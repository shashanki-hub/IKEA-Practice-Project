# 🛒 IKEA Sales Data Analysis

## 📌 Project Overview
This project focuses on analyzing IKEA sales and customer data to identify business trends, understand customer behavior, and generate actionable insights using data analytics tools.

## 🎯 Objectives
- Analyze sales and revenue performance.
- Understand customer segments and purchasing trends.
- Track key performance indicators (KPIs).
- Identify patterns in customer retention and churn.
- Build an interactive Power BI dashboard for business insights.

## 🛠️ Tools & Technologies
- **Microsoft Excel** — Data cleaning and preparation
- **SQL** — Data querying and analysis
- **Power BI** — Interactive dashboards and visualization

## 📊 Dashboard Features
- Total Customers
- Total Revenue
- Average Customer Value
- Customer Churn Percentage
- Revenue by Customer Segment
- Customer Trends by Month, Quarter, and Year
- Revenue Retention Analysis


## 🔍 Key Insights
The dashboard helps explore:
- Which customer segments contribute the most revenue.
- How customer numbers change over time.
- Differences in customer value across segments.
- Customer churn and retention patterns.
